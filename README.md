## How I work

- **If it isn't in Terraform, it doesn't exist.** Clicking in a console is a one-off; the repo is the source of truth.
- **Hardening belongs in the build, not in a patch window.** Golden images ship CIS/STIG-benchmarked and scanned, or they don't ship.
- **Cost is a CI metric, not an end-of-month surprise.** The pipeline flags the bill before anything gets provisioned.
- **An alert nobody can act on isn't an alert, it's noise.** Every page maps to a runbook or it gets deleted.
- **Pipelines should fail fast and loudly.** Slow feedback costs more than a red build ever will.
- **AI narrows the search space during an incident — it doesn't get merge rights.** A human still signs off.
